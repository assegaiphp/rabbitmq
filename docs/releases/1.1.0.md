# AssegaiPHP RabbitMQ 1.1.0

RabbitMQ 1.1.0 moves the queue integration to the AssegaiPHP Common 0.10 release line.

## Compatibility

- requires `assegaiphp/common:^0.10.0`
- continues to require PHP 8.4 or newer and the AMQP extension
- contains no queue runtime behavior changes

## Upgrade

Upgrade RabbitMQ with its dependencies so Composer can replace Common 0.9 with the coordinated 0.10 package:

```bash
composer require assegaiphp/rabbitmq:^1.1 --with-all-dependencies
```

Applications that must remain on Common 0.9 should keep using the RabbitMQ 1.0 release line.
