# AssegaiPHP RabbitMQ 1.1.1

RabbitMQ 1.1.1 repairs typed worker delivery and makes explicit settlement the safe default.

## What changed

- publishes jobs through Common's versioned JSON job envelope
- hydrates each delivery against the processor's declared job type, including legacy raw JSON messages
- processes at most one available message per `process()` call so `queue:work --once`, `--max-jobs`, and empty polling behave correctly
- defaults to manual acknowledgement, acknowledges only after the processor succeeds, and nacks decoding or processor failures
- catches every `Throwable`, retaining both `Error` and `Exception` failures in the process result
- returns the hydrated job in successful and failed process results
- forwards acknowledgement, retry, exchange, routing, and custom codec configuration through `create()`
- declares and binds configured exchanges instead of silently ignoring `exchange_name` and `routing_key`
- removes the unused `ext-amqp` requirement because this driver communicates through PhpAmqpLib
- aligns the README with the current Assegai package format and documents typed processing and settlement options without emoji headings

## Compatibility

- requires `assegaiphp/common:^0.10.1`
- intended to run with `assegaiphp/console:^0.10.3`
- legacy JSON objects remain consumable when the processor declares a compatible concrete job class

## Upgrade notes

Manual acknowledgement is now the default. A successful callback is acked; a failed delivery is nacked with `requeue_on_failure=true` unless configured otherwise. Applications using a dead-letter exchange for poison messages should set `requeue_on_failure=false`.

Direct consumers that previously expected `AMQPMessage` must now accept the domain job object. Transport metadata is no longer passed into application processors.

When `exchange_name` is non-empty, the driver declares that exchange and binds the queue. Ensure `exchange_type`, `exchange_durable`, and `exchange_auto_delete` match any pre-existing broker exchange.

Upgrade the coordinated stack together:

```bash
composer require assegaiphp/rabbitmq:^1.1.1 assegaiphp/common:^0.10.1 assegaiphp/console:^0.10.3 --with-all-dependencies
```
