# AssegaiPHP RabbitMQ 1.2.0

Status: planned; not yet published.

RabbitMQ 1.2.0 moves the adapter to Common 0.11 as part of the coordinated AssegaiPHP 0.11 release. It preserves the adapter's existing version stream: adapter 1.0 accompanied Common 0.9, and adapter 1.1 accompanied Common 0.10.

## Compatibility

- requires `assegaiphp/common:~0.11.0` and removes support for Common 0.10
- uses Core `~0.11.1` for application injection and Console `~0.11.1` for workers
- retains PHP 8.4+, PhpAmqpLib `^3.7`, and the existing queue runtime behavior
- retains the compatible Attributes 1.0 dependency through Common

Lazy connections, typed job hydration, manual acknowledgement and `Throwable` retry handling continue to use the existing contracts. The JSON envelope format is unchanged.

## Upgrade notes

Wait until the coordinated packages are published. Then upgrade the adapter and framework dependencies together:

```bash
composer require "assegaiphp/rabbitmq:~1.2.0" "assegaiphp/common:~0.11.0" "assegaiphp/core:~0.11.1" --with-all-dependencies
```

Upgrade the Console in the environment where workers run to `~0.11.1`. If the other queue adapter is installed, upgrade it to `~1.2.0` in the same Composer operation. Preserve any stricter application requirements and resolve their compatibility before updating.

No queue configuration, job or processor changes are required by this adapter alignment. Applications remaining on Common 0.10 should use RabbitMQ `~1.1.2`.
